# I07: Image Viewer

## State

`COMPLETE_LOCALLY` under ADR-22.

## Delivered

- Inbox thumbnails and placeholders open a full-screen, read-only viewer.
- The viewer displays the source label, size detail, bounded position, explicit
  loading/unavailable state, and close control.
- Previous and next controls stay within a deduplicated snapshot of the loaded
  Inbox window.
- Fit and 2x detail modes reset on image changes.
- MediaStore preview requests use the existing I04 memory cache at 512 px.
- Source-ID matching prevents late asynchronous results from replacing the
  current image.
- Four pure reducer tests cover valid opening, bounded navigation and zoom
  reset, stale-result rejection, unavailable state, and closing cleanup.

## Boundaries

The viewer is a bounded preview, not an original-resolution reader. It adds no
source-byte API, external write, cache persistence, Room change, plan
execution, cleanup, Journal, or recovery behavior.
