## Changes

- `ImportRecord(importId)` conflict tests now prove that `ABORT` preserves the
  original source, target, and state.
- `DraftEntity` rejects unknown states and enforces:
  - `EDITING` requires a non-null `activeKey`;
  - `STALE` and `ARCHIVED` require a null `activeKey`.
- Draft inserts use the semantic `insertEditingDraft` and
  `insertInactiveDraft` DAO methods instead of a generic insert method.
- Draft invalidation and archival tests read the resulting row and prove that
  state and `activeKey` change atomically.
- `insertCommittedImportMetadata` uses a Room transaction for `ImageAsset`,
  target `FileFact`, `AssetFile`, `AlbumMembership`, and `ImportRecord`.
- A conflict during the transaction proves all preceding inserts roll back and
  the existing conflicting row remains unchanged.
- Composite-key tests prove that changing each component remains valid for
  FileFact, AlbumMembership, AssetFile, Evidence, BatchMember, DraftAction, and
  JournalStep.
- Release policy rejects test-only runtime dependencies and production
  references to test Fake implementations.
