## S05.1 Contract

The benchmark receives an explicit budget and measured metrics. It reports:

- `PASS` only for a complete, sufficiently sampled run within every budget.
- `FAIL` for OOM, fetch failures, heap excess, frame P95 excess, or fetch P95
  excess.
- `PENDING` for incomplete or insufficiently sampled runs.
- `INVALID` for impossible metric values.

OOM is fail-closed even when the run terminates before minimum sample counts.
Violation ordering is stable so exported evidence and tests remain comparable.
Budget values are inputs to the classifier; S05.1 does not claim that the
initial values are final production limits.

When a valid run fails, tuning reductions are attempted in this fixed order:

1. reduce prefetch distance;
2. reduce memory-cache capacity to its configured floor;
3. reduce thumbnail cell edge to its configured floor.
