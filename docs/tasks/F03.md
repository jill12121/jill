# F03: Pure Domain Contracts

## Scope

Define the platform-neutral domain contracts needed before fake adapters,
Room, Journal execution, or Android storage behavior are introduced.

This task does not add MediaStore, SAF, filesystem adapters, Room,
WorkManager, source cleanup execution, or real file I/O.

## Delivered

- Added pure Kotlin state enums for Draft, Plan, Album, ImportRecord,
  TrashEntry, and SourceDecision.
- Added state-machine transition guards for the contracted F03 transitions.
- Added Plan type, step type, snapshot, step, and schema validation contracts.
- Added source decision fingerprint protection so decisions are ignored when
  the source key changes.
- Added domain error codes with user-facing message/action metadata.
- Added storage-failure to domain-error mapping.
- Added Android API-level permission matrix contracts for media read, partial
  access, workspace write, and notification behavior.
- Added table-driven domain tests for valid and invalid transitions, plan
  schema validation, decision fingerprinting, error mapping, and permissions.

## Acceptance

- [x] Domain contracts compile as pure Kotlin.
- [x] State machines reject invalid terminal or skipped transitions.
- [x] SourceDecision is not applied after a source fingerprint change.
- [x] Plan schema rejects missing identity, missing creation time, and
  non-contiguous step indexes.
- [x] StorageFailure maps into the frozen domain error table.
- [x] Android 11-15 permission behavior follows the v0.3.1 contract table.
- [x] `:domain:test` passes locally.

## Review Closure

F03.1 corrected the initial Draft/ImportRecord transitions, added typed Plan
payloads and authorization waiting state, separated scan coverage from API
capability, and replaced context-free storage error mapping.

## Deferred

- Fake port implementations.
- FaultPlan and deterministic fault injection.
- SourceDecision and ImportRecord repository persistence.
- Room uniqueness constraints.
- Journal executor and recovery engine.
- Any production Android storage adapter.
