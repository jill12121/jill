# F01: Project, CI, and Dependency Guard

## Scope

Create the Android project shell, static privacy checks, and the delivery
control files. No domain behavior, persistence, storage access, or real file
operations are included.

## Acceptance

- The Android manifest has no `INTERNET` or `MANAGE_EXTERNAL_STORAGE`
  permission and sets `allowBackup=false`.
- The dependency guard rejects network client dependencies.
- The project uses `minSdk=30`.
- The repository has `CONTEXT.md` and `STATUS.md`.

## Fault Path

- `verify-app-policy.ps1` exits non-zero when a forbidden permission or
  dependency is added.

## Fixture

- The checked-in `app/src/main/AndroidManifest.xml` is the passing policy
  fixture.
