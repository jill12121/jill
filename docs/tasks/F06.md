## Delivered Baseline

- first-directory Batch grouping, subgrouping, and a loose-file virtual batch;
- recursive subgroup relative paths within each first-directory Batch;
- normalized `kind:root:path:size:mtimeNormalized` source keys;
- NFC filename sanitization, reserved-name handling, and UTF-8 byte truncation;
- deterministic short image ID collision retry;
- case-insensitive short image ID collision detection;
- fingerprint comparison only when `fpMethod` matches;
- Plan construction over the frozen schema and existing schema validation;
- immutable, generation-bound selection snapshot materialization;
- cross-OEM, Unicode, extreme size/mtime, reserved, long, and duplicate fixtures.
- rejection of root-escaping paths and duplicate selection source keys;
- post-truncation reserved-name and empty-filename protection.

## Boundaries

All code remains pure Kotlin under `domain`; no Android, AndroidX, kotlinx.io,
filesystem access, `.part`, rename, copy, Journal, or production executor is
permitted. Further completion requires reviewable pure-domain requirements and
table-driven tests, not storage integration.
