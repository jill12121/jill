# I03: Source Metadata Catalog

## Acceptance

- Persist discovered `FileFact` and `BatchMember` metadata atomically.
- FULL completed scans replace stale Download membership.
- PARTIAL scans merge visible metadata without sweeping hidden rows.
- Fingerprint changes invalidate prior `SourceDecision` applicability.
- Only exact locator matches in durable `ImportRecord` states show imported.
- A persistence failure does not publish a completed UI scan.
- Room schema remains version 1.

## Out Of Scope

Source bytes, hashing, thumbnails, Draft/Plan creation, external writes,
Journal, WorkManager, source cleanup, and deletion.

## Status

Complete locally on 2026-11-03. Runtime database persistence is wired after a
completed scan; decision authoring remains for a later Inbox interaction.
