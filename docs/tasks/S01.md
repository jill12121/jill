## Scope

The isolated `:spikes:s01-saf` library tests the same SAF primitives intended
for production and is installed only through the `:spikes:probe-suite` APK. It
does not implement a production gateway, Journal, Manifest, copy executor,
cleanup executor, WorkManager, or foreground service.

## Build And Install

```text
gradlew :spikes:s01-saf:testDebugUnitTest :spikes:probe-suite:assembleDebug
apksigner verify --verbose spikes/probe-suite/build/outputs/apk/debug/probe-suite-debug.apk
adb install -r spikes/probe-suite/build/outputs/apk/debug/probe-suite-debug.apk
```

CI must run the same signature verification against the built APK.
For offline validation, transfer and install the APK through the device's
ordinary package installer; ADB and USB debugging are not required.

## Device Runbook

1. In a file manager, create `Download/GalleryOrganizer`. The probe may be used
   to create it through the picker when the provider supports that action.
2. Start the picker, initially positioned at Downloads, and select
   `GalleryOrganizer`. The selected tree is `organizerRoot`; do not select
   Download merely to satisfy the probe.
3. Confirm the probe creates one random `.s01-probe-<128-bit token>` sandbox.
   It must not alter siblings, arbitrary `root.json`, or `.s01-reinstall.bin`.
   Adoption must reject malformed or duplicate marker fields, mismatched
   tokens, unrelated fixed names, and damaged or replaced samples.
4. Run both MIME paths: `application/octet-stream` `.bin.part` to `.bin`, and
   `image/webp` `.webp.part` to `.webp`. Record the metadata classifications;
   non-exact values fail the outcome but do not stop later diagnostics.
5. Record create/rename collisions, repeated `Albums` creation, old-URI
   readability, root/file flags, 64 MB write/read SHA-256 throughput, seek, and
   2k/5k enumeration timings.
6. Force-stop `com.galleryorganizer.spikes.suite`, reopen it, and select
   `Run force-stop retry`. This must perform write, readback, and delete.
7. Reboot the device, reopen it, and select `Run device-reboot retry`.
8. For reinstall adoption, complete one run, uninstall the APK without deleting
   the selected directory, reinstall, reselect the same directory, and run.
   Adoption is permitted only when directory token, marker schema/token,
   sample name, and sample SHA-256 all match.
9. Select `Copy result JSON` and save it using the result template. Never add a
   URI, absolute path, or user filename. Probe-suite 0.1.3 exports only safe
   metadata classes plus the exception class, fixed masked message, and stage.

The probe creates `Albums`, `Review`, `Trash/files`, and `Trash/meta` only
inside its random sandbox. Invalid or damaged ownership candidates are
`NOT_ADOPTABLE` and must not be written, overwritten, or deleted. Every
document created during a run is entered in the cleanup ledger immediately so
later failures cannot leave an untracked probe artifact.

## Single-Device Outcome

Probe JSON uses `PASS`, `PARTIAL`, or `FAIL` in `decisionSingleDevice`.
Root classification is diagnostic and does not determine this value.
A single-run `FAIL` with insufficient diagnostic fields is not an aggregate
device `NO_GO`; rerun with the current probe before classifying a provider
limitation.

## Aggregate Decision

| Result | Rule | Frozen consequence |
|---|---|---|
| GO | Every REQUIRED device completes all core and restart/reinstall checks | Permit an ADR to freeze organizerRoot and `.part` strategy |
| LIMITED_GO | A documented provider limitation has a tested safe fallback on every REQUIRED device | Freeze only that fallback in the ADR |
| NO_GO | Persisted write, exact rename/readback, cleanup, restart, adoption, or required fallback fails | Keep production workspace I/O blocked |

No result is aggregated until all REQUIRED rows are complete. Adding or
replacing a required device row requires an ADR. Emulator/desktop results are
AOSP references only.
