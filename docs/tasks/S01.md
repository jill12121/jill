# S01: SAF Workspace Capability Spike

## State

S01.1 HARDENED_AWAITING_REMOTE_VERIFY. Device execution remains PENDING.

## Scope

The isolated `:spikes:s01-saf` APK tests the same SAF primitives intended for
production. It does not implement a production gateway, Journal, Manifest,
copy executor, cleanup executor, WorkManager, or foreground service.

## Build And Install

```text
gradlew :spikes:s01-saf:testDebugUnitTest :spikes:s01-saf:assembleDebug
apksigner verify --verbose spikes/s01-saf/build/outputs/apk/debug/s01-saf-debug.apk
adb install -r spikes/s01-saf/build/outputs/apk/debug/s01-saf-debug.apk
```

CI must run the same signature verification against the built APK.

## Device Runbook

1. In a file manager, create `Download/GalleryOrganizer`. The probe may be used
   to create it through the picker when the provider supports that action.
2. Start the picker, initially positioned at Downloads, and select
   `GalleryOrganizer`. The selected tree is `organizerRoot`; do not select
   Download merely to satisfy the probe.
3. Run both MIME paths: `application/octet-stream` `.bin.part` to `.bin`, and
   `image/webp` `.webp.part` to `.webp`. Confirm queried names/MIME are exact.
4. Record create/rename collisions, repeated `Albums` creation, old-URI
   readability, root/file flags, 64 MB write/read SHA-256 throughput, seek, and
   2k/5k enumeration timings.
5. Force-stop `com.galleryorganizer.spikes.s01`, reopen it, and select
   `Run force-stop retry`. This must perform write, readback, and delete.
6. Reboot the device, reopen it, and select `Run device-reboot retry`.
7. For reinstall adoption, complete one run, uninstall the APK without deleting
   the selected directory, reinstall, reselect the same directory, and run.
   Record root marker read and legacy file read/write/delete results.
8. Select `Copy result JSON` and save it using the result template. Never add a
   URI, absolute path, or user filename.

The probe creates `Albums`, `Review`, `Trash/files`, and `Trash/meta` directly
under the selected organizer root. `root.json` and one reinstall sample remain
after the first run. Probe performance files and enumeration directories must
be removed.

## Single-Device Outcome

Probe JSON uses `PASS`, `PARTIAL`, or `FAIL` in `decisionSingleDevice`.
Root classification is diagnostic and does not determine this value.

## Aggregate Decision

| Result | Rule | Frozen consequence |
|---|---|---|
| GO | Every REQUIRED device completes all core and restart/reinstall checks | Permit an ADR to freeze organizerRoot and `.part` strategy |
| LIMITED_GO | A documented provider limitation has a tested safe fallback on every REQUIRED device | Freeze only that fallback in the ADR |
| NO_GO | Persisted write, exact rename/readback, cleanup, restart, adoption, or required fallback fails | Keep production workspace I/O blocked |

No result is aggregated until all REQUIRED rows are complete. Adding or
replacing a required device row requires an ADR. Emulator/desktop results are
AOSP references only.
