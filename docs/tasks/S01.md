# S01: SAF Workspace Capability Spike

## State

READY_FOR_DEVICE. The isolated probe APK builds locally; no device result has
been claimed.

## Scope

Verify on Android 11, current target, and at least two OEM families that a
persisted SAF tree grant can support:

- creating or reopening `GalleryOrganizer` under the selected root;
- writing and reading a random `.part` probe;
- renaming `.part` to its final name and reading it back;
- deleting the temporary probe file;
- reopening the grant after force-stop and process restart.

The probe is the separate `:spikes:s01-saf` application. It is not packaged in
the main app release and does not implement `WorkspaceGateway`, Journal,
Manifest, copy execution, or source cleanup.

## Build And Install

```text
gradlew :spikes:s01-saf:testDebugUnitTest :spikes:s01-saf:assembleDebug
adb install -r spikes/s01-saf/build/outputs/apk/debug/s01-saf-debug.apk
```

## Device Runbook

1. Open `S01 SAF Probe`, select the device's `Download` root, and run.
2. Confirm `persisted`, `organizerRoot`, `partReadback`, `cleanup` are `true`.
3. Record `rename` and `finalReadback`; do not record the raw URI or path.
4. Force-stop `com.galleryorganizer.spikes.s01`, reopen it, then select
   `Verify saved authorization`.
5. Confirm `restored=true` and record the final decision.
6. If Download cannot pass, repeat once with `Pictures` and record that as a
   fallback, not as Download success.
7. Confirm no `.s01-*.part` or `.s01-*.bin` remains. Keep the empty
   `GalleryOrganizer` directory for the next run.

## Decision

| Result | Rule | Frozen consequence |
|---|---|---|
| GO | Every target device passes Download create, rename, readback, cleanup, and grant restore | Permit S01 dependents to design against `Download/GalleryOrganizer` |
| LIMITED_GO | Pictures is required, or `.part` readback works but rename is unreliable | Use Pictures fallback and/or direct write plus readback; do not assume atomic rename |
| NO_GO | Persisted write access, directory creation, write/readback, or cleanup fails on any target without a viable fallback | Keep production workspace I/O blocked |

A result is not GO until all required device rows are complete.
