# F05 Workspace Setup

## F05.1 Complete

Compose setup、settings 和 workspace preview 已完成。该阶段没有真实
storage capability。

## F05.2 Complete

目标：让用户通过系统目录选择器选择新建或已有 archive root，并保留
系统授予的 URI 权限。

验收：

- contract 只传递 URI 字符串、显示名和 NEW/ADOPT_EXISTING 模式；
- domain 将 gateway 结果映射为 accepted/rejected，不依赖 Android；
- data/saf 只接受 content tree URI，申请持久 READ/WRITE 权限，并把
  URI、显示名和模式保存到 app-private SharedPreferences；
- presentation 只表达 UNSELECTED/SELECTING/READY/FAILED，不引用 URI、
  ActivityResult、ContentResolver 或 DocumentFile；
- Finish 仅在 root READY 且至少选择一个扫描范围时可用；
- 取消和失败必须可见且不可进入 workspace。

## Excluded

- 目录扫描、workspace 初始化、`.nomedia`、Manifest 读取或写入；
- 文件 copy/rename/delete、source cleanup、Journal 和 recovery；
- Room schema 变更、I01/I02/J1/J2/J3；
- 将缺失物理设备行声明为 PASS、GO 或 release-ready。

## F05.3 Complete

已有根目录接管在 Finish 前执行有界只读校验：

- 严格解析 schema-1 `root.json`；
- 最多读取 256 个 album 的 `manifest.json`，复用 F06 codec；
- 缺失、重复、截断、格式错误或 provider 错误全部 fail closed；
- IMPORTING 只计入待恢复数量，不在本阶段执行恢复；
- 新建根目录流程不执行接管校验。
