# I04: Bounded Paging And Thumbnails

## State

COMPLETE_LOCALLY under ADR-20.

## Delivered

- Platform-neutral generic `ThumbnailSource<T>` contract.
- Read-only MediaStore implementation using
  `ContentResolver.loadThumbnail` with a 256 px default request.
- Successful Bitmap-only LRU caching capped at the smaller of 5% of runtime
  heap and 64 MiB.
- Explicit invalid-reference, access-denied, not-found, and provider-failure
  outcomes. Failures are not cached.
- Room keyset paging by stable `fileId`, capped at 100 returned items with one
  lookahead row. Room schema remains v1.

## Boundaries

No network, disk thumbnail cache, source write, workspace mutation,
full-resolution decode, or presentation-to-DAO dependency. I06c owns loading,
empty, retry, placeholder, and paged UI integration.
