# F02.2: Delivery Quality Hardening

## Scope

Harden reproducible delivery, CI, release privacy checks, and Android packaging
without adding Room, production storage adapters, WorkManager, or real file I/O.

## Delivered

- Regenerated the standard Gradle 8.10.2 Wrapper scripts and retained the
  standard Wrapper JAR.
- Added the official Gradle distribution SHA-256 and marked `gradlew`
  executable in Git.
- Added repository-wide LF rules with CRLF limited to Windows batch files and
  protected the controlled specification baseline from EOL drift.
- Added `.kotlin/` to the build-output ignore rules.
- Added a launcher icon and wired both normal and round icon attributes.
- Added fixture-tested release policy verification for the generated merged
  Manifest and `releaseRuntimeClasspath`.
- Updated CI to use Gradle's setup action and the executable Wrapper for a
  combined `check lint assembleDebug` gate.
- Added release policy fixture tests and real release artifact verification to
  CI.

## Acceptance

- [x] Release merged Manifest rejects `INTERNET`,
  `MANAGE_EXTERNAL_STORAGE`, and `android:allowBackup` other than `false`.
- [x] Release runtime dependencies reject Retrofit, OkHttp, Ktor Client,
  Volley, and Fuel.
- [x] Failure fixtures prove both release policy branches fail closed.
- [x] Wrapper version, distribution checksum, and executable Git mode are
  pinned.
- [x] Baseline, app-policy, release-policy, and architecture guards pass
  locally.
- [x] `check`, `lint`, and debug APK assembly pass locally.
- [x] Lint no longer reports `MissingApplicationIcon`.
- [x] GitHub Actions Verify run `39365176154` passes on Linux for commit
