## Build And Install

After assigning the required device matrix, build and install both APKs. They
have distinct application IDs and Android UIDs. Install probe-suite 0.1.9 and
fixture-helper 0.1.5:

```text
gradlew :spikes:s02-fixture-helper:assembleDebug :spikes:probe-suite:assembleDebug
apksigner verify --verbose spikes/s02-fixture-helper/build/outputs/apk/debug/s02-fixture-helper-debug.apk
apksigner verify --verbose spikes/probe-suite/build/outputs/apk/debug/probe-suite-debug.apk
adb install -r spikes/probe-suite/build/outputs/apk/debug/probe-suite-debug.apk
adb install -r spikes/s02-fixture-helper/build/outputs/apk/debug/s02-fixture-helper-debug.apk
```

For offline validation, transfer and install both APKs through the device's
ordinary package installer in the same suite-first order. ADB and USB
debugging are not required.

## Probe
Open `S02 External Fixture Helper` once. On first launch it automatically
creates one random-token PNG under `Pictures/GalleryOrganizerProbe/` and
copies only the token. Wait for the `S02 fixture token copied` Toast; this does
not depend on the helper screen or button rendering. Open Probe Suite, open
S02, select `Paste fixture token`, then select `Run S02 probe`. The
Activity requests the platform media permission
and records `FULL`, `PARTIAL_USER_SELECTED`, `NOT_GRANTED`, or `DENIED`.
Queries use Bundle keyset arguments with `_ID > ?`, ascending sort, and limit
500. Every page records its index, bounded row count, first/last ID, duration,
duplicate count, strict
ordering, and whether the provider honored the query arguments. Non-monotonic
IDs, ignored arguments, oversized pages, or duplicate IDs cannot PASS.

Before requesting deletion, S02 requires exactly one matching row and validates
`OWNER_PACKAGE_NAME`, relative path, MIME, display name, UUID token, and a
bounded exact payload marker. Metadata is checked before content is read.
Unknown, duplicate, malformed, or non-helper-owned rows cannot reach
`MediaStore.createDeleteRequest` and are never directly deleted by S02.
Authorization batches remain no larger than 300. Cleanup records
`GRANTED_REMOVED`, `GRANTED_STILL_PRESENT`, or `GRANTED_QUERY_FAILED`; only the
first can contribute to PASS. The pending request and result survive Activity
recreation. S02 cannot start a conclusive run until a valid token is pasted.

Schema v2 / probe S02.4 evidence includes structured fixture provenance,
run ID, app version, device model/SDK/manufacturer/security patch, and a
SHA-256 build fingerprint hash. The raw build fingerprint is never exported.
After the cleanup consent flow completes, select `Copy result JSON` and return
the copied payload. The action uses only the system clipboard and requests no
storage permission.
