# I01: Read-only Source Scanner

## I01.1 Scanner Core

- Compose `SourceDiscoveryGateway` pages into one completed discovery snapshot.
- Preserve N01 organizer-root and protected-directory exclusions.
- Bound each page to 500 rows and each scan to 1,000 pages.
- Fail closed on provider errors or invalid pagination contracts.
- Map Android runtime media grants to `ScanCoverage`.
- Declare Android 11-15 media read permissions without requesting them.

## I01.1 Acceptance

- Multiple keyset pages are aggregated exactly once.
- The final page completes the scan and enables whole-batch behavior only for
  `FULL` coverage.
- `PARTIAL_USER_SELECTED` keeps explicit-selection import available while
  whole-batch organization remains disabled.
- Provider failures discard the incomplete aggregate.
- Invalid cursors and oversized pages fail closed.
- Android 11-12, Android 13, and Android 14+ grants map to the expected
  coverage.

## I01.2 User-facing Composition

- Explicit user-triggered runtime permission request.
- Permission rationale, denial, and retry UI.
- Download first-level batch selection and loose-image opt-in.
- Scan progress, retry, and result presentation.
- Persisted organizer-root relative path prevents archive re-scanning.
- Previously granted permission resumes scanning without another prompt.

## Out Of Scope

Source bytes, thumbnails, Room persistence, Plans, external writes, Journal,
WorkManager, cleanup, and deletion.
