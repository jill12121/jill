# I06c: Primary UI Integration

## State

I06c.1 and I06c.2 `COMPLETE_LOCALLY` under ADR-21.

## Delivered In I06c.1

- Production Inbox batch summaries loaded from Room, with explicit loading,
  empty, retry, and append states.
- Stable `fileId` keyset pages of 24 items, deduplicated and bounded to the
  newest 96 visible items.
- Read-only 256 px MediaStore thumbnails with placeholder behavior inherited
  from I04. Compose thumbnail references are pruned with the visible window.
- Persisted source decisions. A current-session edit wins over an older
  persisted value returned by a later page.
- Late page results from a previously selected batch are ignored.
- Production Library starts with a truthful empty state and no preview albums.

## Delivered In I06c.2

- Validated SAF album manifests become a bounded 256-item production catalog.
- Album details expose persisted state and manifest image order without
  inventing title, cover, or thumbnail metadata.
- The metadata editor supports in-memory image reordering for committed
  albums and rejects incomplete, unchanged, or importing-album requests.
- Valid plans contain `APPLY_MANIFEST_PATCH` and `COMMIT_MANIFEST` steps and
  persist as `METADATA/CREATED` in Room v1.
- Plan identity is deterministic for one album manifest revision. Persistence
  conflicts are visible and no plan executor is invoked.

## Boundaries

No Room schema change, manifest write, source-byte write, workspace mutation,
source cleanup, Journal, recovery executor, or J1/J2/J3 behavior. The
96-item Inbox window and 256-item album catalog do not alter external files.
