# N01: Read-only Source Discovery Boundary

## Goal

Define and verify the source-scope model used before scanner implementation.
The milestone discovers bounded image metadata and converts it into selectable
Download batches without reading or changing image content.

## Inputs

- Bounded `MediaStore.Images` metadata pages.
- Current `ScanCoverage`.
- Organizer-root relative path.
- User-maintained protected directory prefixes.
- Selected first-level Download directory names.
- Loose-image opt-in, defaulting to false.

## Acceptance

- First-level Download directories are aggregated with stable image counts.
- Nested directories remain in the first-level batch and expose
  `subgroupRelativePath`.
- Download root files appear in one virtual batch that is disabled by default.
- Organizer-root and protected prefixes are excluded case-insensitively and
  on path-component boundaries.
- `FULL` permits completed whole-batch organization; partial and unknown
  coverage do not.
- The adapter uses strictly increasing `_ID` keyset pages with a maximum size
  of 500 and maps only metadata required by discovery.
- Provider, permission, malformed-row, and pagination failures fail closed.

## Out Of Scope

- Runtime permission UI or app composition.
- Source byte reads, hashing, thumbnails, or analysis.
- Scanner execution, Plan creation, Room persistence, workspace writes,
  Journal, WorkManager, source cleanup, or deletion.
