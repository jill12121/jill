# F02.1: Harden Contracts and Module Types

## Scope

Harden F02 before F03 defines state machines and fake adapters. This remains a
pure-contract task: no Room, SAF, MediaStore, WorkManager, filesystem adapter,
or real I/O is introduced.

## Decisions

- `domain` and `core:contract` remain Kotlin JVM modules.
- `data` and `presentation` are Android Library modules, ready for their
  future Android-specific responsibilities without adding them now.
- Hilt with KSP is the dependency-injection mechanism. The app module is the
  sole composition root; its Hilt module has no bindings until F03 defines
  fake implementations.
- Port failures stay in `core:contract` as `StorageFailure`; user-facing
  error mapping belongs to the domain work in F03.

## Delivered

- Replaced marker ports with asynchronous, capability-neutral signatures and
  value types for read, workspace, deletion, and manifest operations.
- Replaced port-exposing use-case properties with behavior-only interfaces.
- Added a non-empty assertion to the Konsist domain scope.
- Added module-type assertions and a staged I/O policy to the architecture
  guard. F02 permits no I/O; a later explicit `PostSpike` policy restricts
  future platform APIs to named data adapter roots and spike code.

## Acceptance

- [x] `data` and `presentation` compile as Android Library modules.
- [x] `domain` and `core:contract` remain pure Kotlin JVM modules.
- [x] Hilt and KSP generate the application component without bindings.
- [x] Port signatures are compile-safe without Android or filesystem types.
- [x] Use-case interfaces do not expose storage ports.
- [x] Konsist fails when the domain production scope is empty.
- [x] `check`, `lint`, and debug APK assembly pass locally with exit code 0.

## Deferred

- In-memory fakes and FaultPlan belong to F03/F04 after states and error
  contracts are frozen.
- All production Android adapters remain blocked by S01/S02/S04 device GO.
- Release merged-manifest/dependency policy, wrapper normalization, launcher
  icon, and line-ending delivery hardening are scoped to F02.2.
