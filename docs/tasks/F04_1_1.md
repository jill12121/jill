## Safety Semantics

Successful promotion removes only `parts[part.path]`, writes only
`finals[finalTarget]`, and returns that final path with the stored byte size.
An identical target, a target ending in `.part`, or an occupied target returns
`Conflict`.

`writePart`, `promotePart`, `moveToTrash`, and `restoreFromTrash` check target
occupancy before reading input, removing a source, or writing a target. A
conflict therefore preserves source and target bytes across all three maps.
