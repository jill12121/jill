# I05: Draft And Selection Snapshot

## Acceptance

- Create one active batch Draft with typed KEEP/REVIEW/TRASH actions.
- Replace actions only when the expected revision is current.
- Reject missing, duplicate, imported, or invalid selection entries.
- Freeze a valid ORG Plan only when revision, generation, file IDs, and source
  fingerprints match current metadata.
- Persist deterministic selection and ORG payload JSON as CREATED.
- Revising a Draft makes prior unexecuted Plans STALE.
- Room schema remains version 1.
